# Passby Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iPhone app where two people who walk past each other swap a small profile over Bluetooth and later meet in a full-screen checkerboard plaza, with the Dynamic Island outline going green when someone new is waiting.

**Architecture:** A Swift package `PassbyCore` holds everything that can be unit tested (look, profile wire format, plaza rules, persistence). A SwiftUI app target `Passby` holds drawing, screens, Bluetooth, audio and logins behind one `@Observable AppModel`. A widget extension `PassbyLive` renders the Live Activity. No server.

**Tech Stack:** Swift 6 toolchain (language mode 5), SwiftUI, Core Graphics, CoreBluetooth, ActivityKit + WidgetKit, AVFoundation, AuthenticationServices, XcodeGen for the project file, Python + numpy for the music loop.

**Spec:** `docs/superpowers/specs/2026-11-20-passby-design.md`

## Global Constraints

- iPhone only, iOS 17.0 or later. Xcode 26.6. Signing team `62GLRR66AN`.
- Bundle IDs: `com.passbyplaza.app` (app), `com.passbyplaza.app.live` (widget extension).
- No Nintendo characters, art, sounds or music. Everything drawn and synthesised here.
- No server, no accounts, no third-party Swift packages.
- The swapped profile is at most 512 bytes on the wire.
- Every login has a "type your three" path that needs no key and no network.
- Text is system rounded (`design: .rounded`), ink `#4B5560`, soft `#8A949E`, line `#E3E8EC`, fill `#F2F5F7`, green `#37C871`, link `#4AA3C2`. Floor tiles `#F8FCFE` and `#D3EBF4`.
- Sentence case everywhere. Button labels say what happens ("Meet them", "Done").
- Commit after every task, on `main`, ending with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

## Review Focus

1. A profile from another phone with emoji, very long strings or more than three artists: the card truncates, nothing overflows, wire size stays within 512 bytes. Test in Task 1 (`testWorstCaseProfileFitsIn512Bytes`, `testDecodeTrimsOversizedFields`).
2. Bytes from something that is not Passby (random data, empty data, valid JSON of the wrong shape): ignored, no crash, no ghost person. Test in Task 1 (`testGarbageDecodesToNil`).
3. Two phones lying next to each other for the whole demo: one person, one pass, not hundreds. Test in Task 1 (`testRepassInsideCooldownIsIgnored`).
4. Bluetooth off or permission refused, Live Activities switched off in iOS Settings: the plaza, the menus and "Simulate a pass" still work and Settings says what is off. Checked in Task 8 and Task 9 by launching with the capability unavailable in the simulator.
5. A saved state file that is corrupt or from an older build: the app starts with an empty plaza rather than crashing, and keeps the bad file aside. Test in Task 1 (`testCorruptFileLoadsEmptyAndIsKeptAside`).

### Task 1: PassbyCore

**Files:** everything under `PassbyCore/`.

**Interfaces — Produces:**

```swift
public struct Look: Codable, Equatable, Sendable {
  public var skin, hair, hairColor, eyes, mouth, hoodie, extra: Int
  public static let skinCount = 6, hairCount = 8, hairColorCount = 8, eyesCount = 5,
                    mouthCount = 5, hoodieCount = 10, extraCount = 6
  public static let hairNames  = ["Crop","Swoop","Bun","Long","Curls","Buzz","Spikes","Bob"]
  public static let eyesNames  = ["Round","Tall","Sleepy","Happy","Wink"]
  public static let mouthNames = ["Smile","Grin","Flat","Smirk","Oh"]
  public static let extraNames = ["None","Glasses","Cap","Headphones","Beanie","Bow"]
  public static let starter: Look            // skin 1, hair 1, hairColor 0, eyes 0, mouth 0, hoodie 5, extra 0
  public func clamped() -> Look              // every index wrapped into its range
  public static func random<G: RandomNumberGenerator>(using g: inout G) -> Look
}
public struct Profile: Codable, Equatable, Identifiable, Sendable {
  public var id: UUID, name: String, look: Look, instagram: String
  public var artists: [String], games: [String], greeting: String
  public static let maxWireBytes = 512
  public func normalized() -> Profile        // trims, strips a leading "@", caps counts and byte lengths
  public func wireData() -> Data             // compact JSON of normalized(), always <= 512 bytes
  public init?(wireData: Data)               // nil unless well-formed; result is normalized
}
public struct Encounter: Codable, Equatable, Identifiable, Sendable {
  public var profile: Profile, times: Int, firstMet: Date, lastMet: Date, waiting: Bool
}
public enum PassOutcome: Equatable, Sendable { case new, again, ignored }
public struct PlazaState: Codable, Equatable, Sendable {
  public var me: Profile?, encounters: [Encounter]
  public var passingOn = true, musicOn = true, soundsOn = true
  public var spotifyLinked = false, steamLinked = false
  public static let repassInterval: TimeInterval = 600
  public mutating func recordPass(_ p: Profile, at now: Date) -> PassOutcome
  public var waiting: [Encounter] { get }    // oldest lastMet first
  public mutating func greet(_ id: UUID)
}
public final class Store {
  public init(directory: URL)
  public func load() -> PlazaState
  public func save(_ state: PlazaState) throws
}
```

Byte caps in `normalized()` (UTF-8, cut on character boundaries): name 24, instagram 30, each artist and game 36 with at most 3 of each, greeting 80. Wire keys: `v` (1), `i`, `n`, `l` (7 ints in the order above), `g` (instagram), `a`, `p` (games), `h` (greeting). If the encoded form still exceeds 512, drop the greeting, then the third artist and game.

`recordPass` rules: own id is ignored; unknown id is appended with `times` 1 and `waiting` true and returns `.new`; a known id always gets its profile refreshed, and if `now - lastMet >= repassInterval` gets `times + 1`, `lastMet = now`, `waiting = true` and returns `.again`; otherwise `.ignored`.

`Store` writes `state.json` atomically. On a decode failure `load()` renames the file to `state.corrupt.json` and returns `PlazaState()`.

### Task 7: Sound and music

**Files:** `Services/Audio.swift`, `tools/make_music.py`, `Resources/theme.wav`.

**Interfaces — Produces:**

```swift
@MainActor final class Audio {
  var soundsOn: Bool; var musicOn: Bool        // setting musicOn starts or stops the loop
  func blip(); func jingle(); func voice(letter: Character, pitch: Int)
}
```

Sounds are sine tones with a 12 ms attack and exponential decay, rendered into PCM buffers and played through one `AVAudioEngine`. Session category `.playback` with `.mixWithOthers`, so a phone on silent still plays at the demo. Jingle: MIDI 67 72 76 79 84 at 85 ms spacing, then a held 72 76 79 84 chord. Voice pitch per person is `60 + (first byte of the id % 20)`.

`tools/make_music.py` renders an original 16-bar loop at 96 bpm, 44.1 kHz mono 16-bit: soft electric-piano chords Cmaj7, Am7, Dm7, G7 (two bars each, twice), a root-and-fifth bass, a shaker on off-beats and an original pentatonic melody. Note tails wrap around the end so the loop is seamless. Peak normalised to -3 dBFS. The script prints duration and peak.
